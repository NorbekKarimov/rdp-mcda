The input stacks (`orol_v2_1000m`, `orol_v2_100m`, `orol_v2_30m`; NumPy `.npy` arrays of shape (8, K), float32, with `meta.json`) are not stored in this repository because of their size (up to 2.4 GB). They are available from the corresponding author on reasonable request and can be regenerated with the Earth Engine script in `gee/`. See `data/README.md`.
